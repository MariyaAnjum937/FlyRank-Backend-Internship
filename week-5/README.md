# Book Scraper

A small web-scraping project built for an internship assignment using **Books to Scrape**, a sandbox website designed specifically for practising web scraping.

## Target classification

* **Target:** [Books to Scrape](https://books.toscrape.com/)
* **Purpose:** The site is a scraping sandbox created for people to practise web scraping.
* **Scope:** The scraper will collect data from the **first 3 catalogue pages only**.
* **Data collected:** Book title, price, availability, rating, and product URL.
* **Robots.txt:** No robots.txt file found.
* **Why this target is appropriate:** Books to Scrape is intentionally provided as a practice environment for web scraping, making it suitable for this assignment.

A missing robots.txt file is not treated as permission to scrape other websites.

> I will not reuse this code on another site without checking its rules and terms first.
